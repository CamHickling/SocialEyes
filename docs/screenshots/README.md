# Screenshots

One participant session of the example study (`studies/example`, participant P005),
taken on a Pixel 3 (1080 x 2160) with app version 0.1.0. `00_overview.png` shows them
all on one page.

| File | Screen |
|---|---|
| `01_setup.png` | Researcher setup: pick the study and participant |
| `02_instructions.png` | Instructions step |
| `03_calibration.png` | Marker calibration: AprilTags in the corners for the eye tracker's scene camera |
| `04_validation.png` | Gaze validation: look at each dot and tap it |
| `05_questionnaire.png` | Questionnaire, visual analogue scale |
| `06_feed.png` | Feed: stories row and the first post |
| `07_post_labelled.png` | Critical post (retouching manipulation) with the "digitally altered" label |
| `08_post_comments.png` | The same post: likes, caption, comments (comment-valence manipulation) |
| `09_liked.png` | Double-tap like with heart animation |
| `10_comments_sheet.png` | Comments sheet |
| `11_rating.png` | Image rating (attractiveness, realism) |
| `12_recognition.png` | Recognition test with confidence |
| `13_end.png` | End screen |

Notes:

- All images, avatars and accounts are generated placeholders, not real people.
- The small dark square in the top-left corner is the **sync patch**: it flickers in
  a pseudorandom code so the eye tracker's video can be synchronised with the phone's log.
- "Pictogram" is a neutral name; the app imitates the look of a photo-sharing feed
  without any real platform's name or logo.
